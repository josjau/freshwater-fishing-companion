# Purpose

This document records notable changes to Freshwater Fishing Companion.

The changelog provides a chronological history of project milestones, feature additions, documentation updates, bug fixes, and architectural improvements.

Entries should summarize user-visible or project-significant changes rather than every individual commit.

---

# Format

The project generally follows the principles of [Keep a Changelog](https://keepachangelog.com/) while remaining lightweight.

Each release should include, where applicable:

- Added
- Changed
- Fixed
- Removed
- Deprecated

Not every release requires every section.

# Versioning Philosophy

Planning milestones use pre-release version numbers.

The application reaches Version 1.0.0 when:

- Core functionality is implemented.
- Documentation is complete.
- Testing is complete.
- The application is considered ready for general use.
