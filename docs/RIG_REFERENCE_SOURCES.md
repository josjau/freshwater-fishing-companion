# Purpose

This document records external Rig references and approved tutorial-video sources used by the application.

These sources are used for visual confirmation and technical cross-checking. Their images or videos are not copied into the repository unless a separate asset-level licensing review explicitly permits reuse. Official platform embedding remains platform-hosted content and does not transfer reuse rights.

Primary embedded Rig tutorials follow the build-first standard in `MEDIA_GUIDE.md`: correct assembly/build is the main purpose, concise/direct sources are preferred when technically complete, and technique/retrieve/presentation content must remain secondary.

# Embed Standard

Approved YouTube tutorials use the official YouTube player in privacy-enhanced `youtube-nocookie.com` mode, are created only after the user selects **Load tutorial**, do not autoplay, remain responsive at phone widths, preserve normal YouTube branding/controls, and retain a separate `Watch on YouTube ↗` fallback.

# Link Semantics

Ordinary reference links use `↗` because they open an external source in a new tab.

Approved embedded tutorials remain in the application through the source platform player and provide a separate external-source fallback using `↗`.

The contextual `ⓘ` convention remains reserved for information displayed without leaving the current application page.
