# Data Model

This directory contains the canonical data model for Freshwater Fishing Companion.

The data model is divided into focused documents to improve readability, maintainability, and long-term scalability.

## Documents

01 - Foundation

Defines the overall philosophy, standards, identifiers, and data principles.

02 - Fish

Canonical fish species, identification traits, habitats, and relationships.

03 - Rigs

Rig definitions, components, assembly, and relationships.

04 - Knots

Fishing knot definitions and instructional data.

05 - Tackle

Canonical tackle types, product definitions, inventory relationships, and ownership.

06 - Lures

Lure definitions, colors, dimensions, product codes, and actual-size image support.

07 - User Data

Profiles, preferences, favorites, inventory, catch logs, and related entities.

08 - Backup

Backup format, validation, restore workflow, schema versioning, and migration.

09 - Relationships

Entity relationships, identifiers, validation rules, and deferred decisions.
