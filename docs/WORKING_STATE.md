Unknown preferred/descriptive data never silently qualifies as Exact/Preferred, while unknown fishing-relevant data may remain Usable Functional only when the family contract does not require it for compatibility. A Recommendation is currently executable only when every required availability-bearing requirement has an Exact/Preferred or Usable Functional match.
