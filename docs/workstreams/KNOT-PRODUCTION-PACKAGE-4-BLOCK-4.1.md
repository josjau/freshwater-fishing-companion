# Approved Changes Applied

## Dropper Loop Knot

Old Version 1 instruction:

- five wraps.

New Version 1 instruction:

- wind one side of the loop around the other **about six times** while preserving the central opening and original branch loop.

Reason:

- the project approved Animated Knots as the primary external instructional source for supported Version 1 Knots,
- Animated Knots demonstrates approximately six wraps for the selected Dropper Loop method,
- six wraps remains within the independently researched Dropper Loop family range.

The production record now includes:

`https://www.animatedknots.com/dropper-loop-knot`

as a verified reference.

## Snell Knot

Old Version 1 method:

- Easy Snell.

New Version 1 method:

- **traditional loop-wrapped Snell**.

Difficulty remains:

`Intermediate`

Locked production method:

1. pass the leader through the hook eye,
2. pass through the eye again in the same direction and leave a large loop,
3. control the doubled line and loop beside the shank,
4. wrap the large loop around the hook shank and doubled line **seven to eight times**,
5. pull the standing line to collapse the remaining loop beneath the coils,
6. moisten, seat the coils, verify alignment, and trim.

The production record now uses:

`https://www.animatedknots.com/snell-knot`

as the primary verified instructional reference.
