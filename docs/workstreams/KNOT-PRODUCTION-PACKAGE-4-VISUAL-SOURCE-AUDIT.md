# Purpose

Identify the best technically correct instructional visual for each active Version 1 Knot before any Package 4 production media is packaged or integrated.

# Approved Source Priority

For every Knot, evaluate media in this order:

1. verified diagram,
2. verified animation,
3. verified video,
4. custom project diagram only as a last resort.

Canonical Knot text remains authoritative.

A candidate is rejected when it teaches a legitimate variation that does not match the locked Version 1 method.

# Audit Requirements Per Knot

For each Knot record:

- confirm canonical method/topology,
- record serious diagram candidates first,
- if no diagram passes, record animation candidates,
- if no diagram/animation passes, record video candidates,
- verify the actual depicted tying method step by step,
- record creator/source,
- record reuse or embedding status,
- record technical strengths and failure risks,
- select the strongest candidate or record that no external source passes,
- obtain explicit user approval before production packaging.

# Candidate Status Legend

- **PASS — preferred candidate:** technically matches the canonical method and has an acceptable production delivery path.
- **PASS — reference only:** technically useful, but reuse/embedding rights or presentation make it unsuitable as the production visual.
- **HOLD — requires deeper audit:** promising candidate but one or more critical geometry/method details remain unresolved.
- **REJECT:** wrong method/variation, obscured geometry, inadequate source quality, or unacceptable rights/delivery path.
