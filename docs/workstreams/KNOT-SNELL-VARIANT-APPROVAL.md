# Knot Snell Variant Approval

**Status:** Approved  
**Milestone:** Knots  
**Package:** Production Package 4  
**Approved:** 2026-08-14

# Purpose

Record the approved Version 1 Snell-method change identified during the 10-Knot Visual Source Audit.

# Approved Change

**Old canonical method:** Easy Snell  
**New canonical method:** Traditional loop-wrapped Snell  
**Canonical ID:** `snell-knot`  
**Difficulty:** `Intermediate` — unchanged

The change is approved because the traditional loop-wrapped Snell has materially stronger visual teaching support while remaining appropriate for the same canonical Snell entity.

# Locked Version 1 Tying Method

The approved Version 1 method is:

1. Pass the leader through the hook eye.
2. Pass the leader through the eye a second time in the same direction, leaving a large loop beside the hook.
3. Hold the hook eye and the two line sections together so the loop remains controlled beside the hook shank.
4. Wrap the large loop around the hook shank seven to eight times, keeping the coils orderly and adjacent.
5. Pull the standing line to shrink the remaining loop beneath the coils while holding the wraps in place.
6. Moisten the connection, pull the standing line and tag end to seat the coils firmly around the shank, then trim the excess tag end.

# Primary Technical Reference

**Animated Knots by Grog — Snell Knot**  
`https://www.animatedknots.com/snell-knot`

This source provides the strongest current step-controlled visual reference for the approved method and explicitly demonstrates:

- two passes through the eye in the same direction,
- a large controlled loop,
- seven to eight loop wraps around the hook shank,
- collapse of the loop by pulling the standing end,
- final tightening with orderly coils.

The source is a technical and external visual reference. Its copyrighted animation/frames must not be copied or bundled without separate permission.

# Independent Corroboration

**Tackle Tactics — Snell Knot (Traditional)**  
`https://www.tackletactics.com.au/blogs/learn-to-fish/snell-knot-traditional`

Tackle Tactics provides an illustrated traditional Snell sequence using the same loop-wrapped knot family and approximately six to seven wraps. It is corroborating evidence rather than the source for the locked seven-to-eight-wrap standard.

**Take Me Fishing — How to Tie a Snell Knot**  
`https://www.takemefishing.org/how-to-fish/how-tie-fishing-knots/how-to-tie-a-snell-knot/`

Take Me Fishing remains useful for Snell applications and general compatibility evidence, but its Easy Snell tying sequence is no longer the Version 1 canonical method.

# Difficulty Decision

The difficulty remains `Intermediate`.

The traditional method adds a second pass through the hook eye and manipulation of a larger loop, but removes the Easy Snell's small direction-sensitive tag-end return. The overall dexterity and sequence-management burden changes without materially increasing.
